# Domain checklist

## Common failure patterns

- Grading only the final prose.
- Using identical generic prompts for unrelated skills.
- Inflating success by excluding blocked cases silently.

## Review questions

- Each behavioral case contains a concrete prompt and expected actions.
- Critical forbidden actions are explicitly graded.
- Missing runtime access yields not-run, not pass.

## Worked boundary

Only deterministic routing tests have run. Report routing results separately and leave behavioral reliability unknown.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
