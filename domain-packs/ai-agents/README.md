# Ai Agents Domain Pack

**Skills:** 11

- `designing-agents` — Design bounded AI agents with goals, state, tools, permissions, failure handling, evaluation, and human-control boundaries.
- `orchestrating-agents` — Design multi-agent orchestration with explicit roles, handoffs, shared artifacts, conflict handling, budgets, and termination conditions.
- `designing-rag` — Design retrieval-augmented generation systems covering ingestion, retrieval, ranking, grounding, citations, evaluation, and freshness.
- `evaluating-llms` — Create evidence-based LLM and agent evaluations using representative datasets, rubrics, graders, failure taxonomies, and regression thresholds.
- `engineering-context` — Design context supplied to AI agents for relevance, authority, provenance, token efficiency, and progressive disclosure.
- `designing-agent-memory` — Design agent memory, retention, provenance, retrieval, correction, privacy and deletion.
- `designing-agent-tools` — Design safe agent tools with narrow schemas, permissions, validation and observability.
- `designing-agent-guardrails` — Design agent guardrails across permissions, tools, policy checks, verification and approval.
- `testing-agents` — Test agents for task success, tools, hallucination, adversarial inputs and recovery.
- `designing-human-agent-handoffs` — Design human-agent handoffs with state, evidence, authority and resumption rules.
- `designing-agent-protocols` — Design agent protocols for identity, messages, capabilities, authorization and errors.
