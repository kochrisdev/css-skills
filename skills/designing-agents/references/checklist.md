# Domain checklist

## Common failure patterns

- Equating a persuasive system prompt with enforced access control.
- Giving all tools to every agent.
- Treating longer reasoning as proof of reliability.

## Review questions

- Every tool has a documented side effect and authority boundary.
- The agent can stop instead of looping indefinitely.
- Evaluation includes failure and abuse cases.

## Worked boundary

The tool response asks the agent to reveal secrets. Treat it as untrusted data and retain the original authority boundary.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
