# Fintech Domain Pack

**Skills:** 7

- `designing-ledgers` — Design auditable double-entry financial ledgers with postings, invariants, idempotency, reconciliation, corrections, and temporal history.
- `designing-kyc` — Design KYC and customer due-diligence workflows with risk tiers, evidence, review states, privacy boundaries, escalation, and auditability.
- `designing-aml` — Design AML workflows covering screening, transaction monitoring, alert triage, case handling, escalation, and audit evidence.
- `designing-fraud-controls` — Design layered fraud controls using threat scenarios, behavioral and transaction signals, decisioning, step-up controls, and feedback loops.
- `designing-wallets` — Provide a governed designing wallets capability with explicit scope, evidence, verification, failure handling, and permission boundaries.
- `designing-merchant-payments` — Provide a governed designing merchant payments capability with explicit scope, evidence, verification, failure handling, and permission boundaries.
- `designing-transaction-limits` — Provide a governed designing transaction limits capability with explicit scope, evidence, verification, failure handling, and permission boundaries.
