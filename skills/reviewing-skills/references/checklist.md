# Domain checklist

## Common failure patterns

- Approving because every required heading exists.
- Ignoring unlinked support files.
- Confusing manual invocation with tool permission enforcement.

## Review questions

- Findings cite exact instruction or code locations.
- Safety guidance is not described as an enforced sandbox.
- The review does not promote a skill based on file count.

## Worked boundary

A skill has four evaluation headings but no prompts or expected behavior. Classify it as lacking behavioral test cases.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
