# Security Domain Pack

**Skills:** 9

- `security-reviewing` — Assess implementations or architectures for concrete security weaknesses and control gaps; use before sensitive releases.
- `threat-modeling` — Create threat models covering assets actors trust boundaries attack paths risks and mitigations; use for security-sensitive systems.
- `reviewing-authentication` — Review authentication, credentials, MFA, sessions, recovery and abuse resistance.
- `reviewing-authorization` — Review authorization, least privilege, object access, tenancy and privilege escalation.
- `reviewing-api-security` — Review API authentication, authorization, validation, limits, secrets and data exposure.
- `auditing-secrets` — Audit secret exposure, storage, scope, rotation and remediation.
- `reviewing-dependencies` — Review dependency provenance, vulnerabilities, maintenance, licenses and supply-chain exposure.
- `modeling-abuse` — Model abuse involving legitimate interfaces, identities, automation and business logic.
- `reviewing-cloud-security` — Review cloud identity, network boundaries, data protection, logging, keys and configuration.
