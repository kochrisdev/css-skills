# Software Development Workflow

## Sequence

1. `analyzing-requirements`
2. `creating-prds`
3. `system-design`
4. `planning-projects`
5. `implementing-code`
6. `reviewing-code`
7. `verifying-products`
8. `gating-releases`
9. `deploying-safely`

## Rules
Consume explicit evidence; skip only evidenced stages; stop at approval boundaries; route verification failure back to the owning stage.
