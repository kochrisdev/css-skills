# Domain checklist

## Common failure patterns

- Creating a new policy file for every edit.
- Copying an outdated example into multiple guides.
- Deleting decision history while simplifying navigation.

## Review questions

- Each repeated concept has a clearly designated canonical source.
- A new reader can locate installation and validation from the README.
- Historical records remain distinguishable from current instructions.

## Worked boundary

A command cannot be executed on the available OS. Label it untested and provide prerequisites rather than a fake success transcript.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
