# Domain checklist

## Common failure patterns

- Always returning five results even when none fits.
- Labeling a lexical score as a probability of success.
- Assuming every catalog entry is installed.

## Review questions

- All returned names exist in the catalog.
- Draft status is never hidden.
- An unrelated query can return no match.

## Worked boundary

The best word match is a draft with no specific procedure. Return its status and prefer abstention or a pilot alternative.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
