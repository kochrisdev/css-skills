# Domain checklist

## Common failure patterns

- Calling TF-IDF semantic intelligence.
- Letting prompt-injected source text select privileged tools.
- Treating a high match score as user consent.

## Review questions

- Routing is explainable and can abstain.
- Drafts are opt-in.
- No routed action executes automatically.

## Worked boundary

A request mixes documentation review with live deletion. Separate the tasks and retain the explicit authorization boundary.

This is authored engineering guidance, not a legal opinion, live observation or certification. Validate jurisdiction-specific, version-specific and environment-specific requirements from authoritative sources.
