# Verification records

`verification.json`, `unit-tests.txt`, other v0.5 reports and `v04-audit.json` are historical snapshots.
Their counts and execution environments describe package-generation time, not current repository state.
For the PE/VC extension use `pe-vc-verification.json`, `pe-vc-unit-tests.txt`, and `pe-vc-routing.json`.
GitHub checks attached to the update PR are separate, fresh runtime evidence. A local pass is not a CI result.
No report establishes live-agent behavioral performance or expert financial review.
